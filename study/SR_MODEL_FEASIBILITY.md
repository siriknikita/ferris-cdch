# Modern super-resolution feasibility

**Assessment date:** 16 November 2026. This workspace had nine visible CPU threads on an Intel Xeon Platinum 8573C, no visible GPU device, and the recovered CPU-only PyTorch 2.7.1 environment. The official DIV2K host timed out over the workspace's execution network. The verified local DIV2K and SwinIR/Real-ESRGAN assets sufficed for this stage. No new diffusion weights were downloaded. Memory and wall time for the candidates below are unmeasured here.

| Candidate | Implementation, availability and terms | Output and pair construction | Feasibility decision |
|---|---|---|---|
| SUPIR | Author code, Q and F checkpoints, and SDXL and LLaVA dependencies. The current author license has noncommercial terms and a separate commercial licensing route [1]. | CLI exposes scale and minimum output size. The documented minimum-size default is 1024. Use a sufficiently large context so the requested ×2 scale produces the reference geometry without an extra resize. Use Q/F as separate conditions. | Multi-checkpoint and large-context setup. Defer until a CUDA resource and suitable storage are available. Establish peak VRAM and wall time on one exact-geometry image before a full cohort. |
| DiffBIR | Official ECCV 2024 implementation. The repo supplies multiple IRControlNet checkpoints and first-stage weights, CUDA examples and tiled sampling [2]. Code license is Apache-2.0. Check model and base-checkpoint terms separately. | Demo uses ×4 and 50 steps for v2. Use a pinned ×2 configuration only after confirming pixel geometry. Otherwise run ×4 with comparably constructed controls. The generic SR checkpoint is the initial comparison. | Tiling and a disabled captioner reduce the expected footprint. Published example settings do not supply a measured runtime or VRAM estimate for this exact paired workload. |
| SeeSR | Official CVPR 2024 repo. Requires SD-2-base, SeeSR, and DAPE weights. It supplies author download links and tiled VAE. Code license is Apache-2.0. The authors document LSDIR and FFHQ training sources [3]. | Record caption/tagger policy, tile settings, seed, final dimensions and plausible source overlap. Keep any size normalization identical across conditions. | Multi-checkpoint setup with face-data provenance to check before testing on a face cohort. CUDA smoke test required. |
| HYPIR | Author SIGGRAPH 2025 repository provides a diffusion-prior-derived restoration model and author checkpoints [4]. The repository license distinguishes open source components and proprietary neural components. Confirm written permission for any proprietary checkpoint. | Evaluate the same scale, context and final alignment as a separate single-step generative restoration condition. Record exact base model and tiled inference settings. | The authors report a T4 Colab example. Evaluate only after confirming weight permission. Peak VRAM and throughput on matched pairs still require measurement. |
| Topaz Gigapixel Redefine | Commercial product with documented local/cloud rendering options. Output may differ across backends. The docs expose Realistic and Creative settings, and optional prompts [5]. | Native size/scale controls are documented. Pin app version, model label, local backend, export settings and prompts. Check authorization to use exported outputs for this research before acquisition. | Commercial scope, model version pinning and output-use terms are unresolved. Consider a small separately tracked test after a reproducible author-released model. |

Author examples describe restoration quality and released assets. They do not establish the paired reconstruction quality on these source photographs. The smoke test should check image dimensions, alignment, exact input and output hashes, codec, per-image wall time, peak CPU/GPU memory and failure rates. For observable distortion, record PSNR on aligned references and a perceptual metric reported with its version. Keep natural detail plausibility and visible hallucination notes alongside the quantitative checks. Fix one common LR degradation for the initial comparison, include bicubic and a second conventional reconstruction, and reserve an independent source split. Keep the source restoration stage outside the classifier inference benchmark.
